## التشغيل السريع

```bash
cd CDOW

npm start
```

افتح **http://localhost:3000** — بدون بوت تيليجرام الموقع يشتغل، بس تسجيل الدخول يحتاج بوت.

> Node.js 18 أو أحدث مطلوب.

## إعداد بوت تيليجرام (CDOW)

1. افتح **@BotFather** في تيليجرام
2. أرسل `/newbot`
3. الاسم: `CDOW` — واليوزر: اختار مثل `CDOWBot`
4. انسخ التوكن
5. انسخ `.env.example` إلى `.env` واملأ:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
   BOT_USERNAME=CDOWBot
   SITE_URL=http://localhost:3000
   ```
6. أعد تشغيل السيرفر

الآن زر "Login via Telegram" بالموقع → يفتح البوت → ترسل `/login` → يوصلك كود 6 أرقام → تحطه بالموقع → دخول!

## إعداد القناة (إعلانات الفوز)

1. أنشئ قناة باسم **CDOW** (مثلاً @CDOWChannel)
2. اضيف البوت **ادمن** بالقناة
3. حط معرف القناة في `.env`:
   ```
   TELEGRAM_CHANNEL_ID=@CDOWChannel
   ```
4. البوت راح يعلن تلقائياً عن: الفوز الذهب من الكيسات، جاكبوت ×14، جولات ×50، Royal كبير، والمعارك الغالية

## نظام الإحالة (Referral)

- رابطك: `https://t.me/YourBot?start=ref_XXXX` (من صفحة Tasks أو /ref بالبوت)
- كل صديق يسجل → **+5000 عملة** فوراً، بدون حدود

## الشحن والمدفوعات

`.env`:
```
PAYMENTS_MODE=sandbox   # sandbox للتجربة (يقبله تلقائياً بعد 4 ثواني)
PAYMENTS_MODE=live      # الحقيقي — الأدمن يوافق يدوياً
CRYPTO_BTC=bc1q...      # عنوان البيتكوين
CRYPTO_ETH=0x...        # عنوان الإيثريوم
CRYPTO_USDT=T...        # عنوان USDT TRC20
PAYPAL_LINK=https://paypal.me/yourname
```

**سير العمل الحقيقي:** المستخدم يرسل كربتو → يحط TXID → يظهر عند الأدمن → موافقة → تضاف العملات (+6500 مهمة أول شحن تلقائياً).

> ملحوظة مهمة: لقبول بطاقات حقيقية مباشرة تحتاج بوابة دفع (Stripe مثلاً) — الواجهة والدفق جاهزين، والإضافة سهلة بنفس النمط.
